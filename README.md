# Terras Raras — Mining Tycoon (v4.2 - Save 100% na Nuvem Firebase)

Versão completa e corrigida com sincronização e salvamento direto no **Firebase Firestore** (sem depender de `localStorage`).

## Configuração do Firebase Integrada:
- **Projeto:** `terras-rara-v1-pro`
- **Autenticação:** Anônima automática (`signInAnonymously`)
- **Banco de Dados:** Cloud Firestore na coleção `saves/{uid}`

## Como testar:
1. Extraia o ZIP.
2. Abra o arquivo `index.html` em um navegador moderno (ou sirva via Live Server / GitHub Pages).
3. Certifique-se de que o provedor **Anônimo** está ativado no seu Console do Firebase (Authentication > Sign-in method).
