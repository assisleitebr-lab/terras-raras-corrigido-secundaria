# Terras Raras — Mining Industry (Expansión v2.0 - O Legado & Firebase)

Protótipo web avançado de simulador educativo de mineração, processamento e fabricação de terras raras, integrado com **Firebase Firestore** e contendo a nova **Fase de Exploração Espacial e Homenagem (O Legado de VovôBrDias)**.

## Como executar

1. Baixe e extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. O progresso é salvo no `localStorage` e sincronizado com o Firebase (`terras-rara-v1-pro`).

## Novidades na v2.0
- 5 novas missões avançadas (total de 15 missões).
- Novos materiais de alta tecnologia: Bateria de Estado Sólido, Núcleo de Propulsão Magnética e o Módulo Espacial Homenagem (Projeto VovôBrDias).
- Novos processos industriais de fronteira tecnológica.
- Temas visuais estelares para a fase final.
