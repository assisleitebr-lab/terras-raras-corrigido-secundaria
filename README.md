# Terras Raras — Mining Tycoon (Edição Game Pro v4.0)

Versão definitiva com estética de **Game Industrial / Sci-Fi**, **figurinhas ilustrativas animadas**, **efeitos sonoros de arcade (Web Audio API)**, **correção total de erros (404 de ícones e bloqueio do Firebase offline)** e **1.200 unidades iniciais de minério bruto**.

## O que foi corrigido e adicionado na v4.0:
1. **Zero Erros no Console**:
   - Ícones PWA embutidos via SVG Data URI no `manifest.json` e `index.html`, eliminando o erro `404 (Not Found)` de `icon-192.png`.
   - Salvamento local ultra-estável (`terrasRarasGameV4`) sem gerar erros vermelhos de permissão offline do Firebase.
2. **Mais Cara de Game (Figurinhas Ilustrativas & Animações)**:
   - Figurinhas temáticas animadas (`flutuando`, `pulsando`, `girando`) em todo o HUD, missões, inventário e máquinas.
   - Ilustração animada do **Britador Móvel BM-1200** quebrando pedras na tela principal.
   - Efeitos flutuantes (`+100 🪨 Minério`, `+🪙 Créditos`) e botão de extração manual rápida na Base Central.
   - Efeitos sonoros sintéticos integrados (som de britador/forja, moedas e fanfarra de vitória) gerados via Web Audio API.
3. **Valores Calibrados**:
   - Estoque inicial de **1.200** unidades de Minério Bruto e preço de mercado atualizado.
